# ClipMoa 지원·개인정보처리방침

ClipMoa(iPhone 앱)의 공개 페이지입니다. GitHub Pages 로 게시합니다.

- 지원: https://mcred2030.github.io/clipmoa/ (영어 https://mcred2030.github.io/clipmoa/en/)
- 개인정보처리방침: https://mcred2030.github.io/clipmoa/privacy/ (영어 https://mcred2030.github.io/clipmoa/en/privacy/)

같아야 합니다(스토어판 앱 안의 방침 화면도 그 파일들을 씁니다). 방침을 고칠 때는 두 언어 모두, 두 곳을 함께 고칩니다.
